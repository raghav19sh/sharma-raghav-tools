# Sharma-Raghav Tools

A focused collection of free image, PDF, calculator, converter, text and utility tools.

Production target: https://tools.sharma-raghav.com

## Features
- Dedicated URL for every tool.
- Browser-first processing where practical.
- No accounts.
- No permanent file library.
- SEO metadata, sitemap and robots.
- AdSense-ready with real publisher IDs supplied only through environment variables.

## Run locally
npm install
npm run dev

## Build
npm run build
